# Описание проетка

*"Это программа на Python с графическим интерфейсом (Tkinter), которая работает как генератор случайных задач.

Основные функции:
Генерация: выбирает случайную задачу из встроенной базы.
История: отображает историю сгенерированных задач в виде списка.
Фильтрация: позволяет выводить фильтрацию по типу задачи.
Управление данными: можно добавлять новые задачи в базу, сохранять историю в JSON и загружать обратно.

## Требования

* Python 3.6+
* Библиотеки: `tkinter` (встроен в Python), `json` (встроен в Python)
